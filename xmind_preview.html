    • 日志同步
      • 报告导出
        • 逆向场景
          • 软件执行码检测工具|报告导出失败+日志同步处理 功能测试 P2
            1.登录OS门户并跳转到工具<br>2.在工具侧执行报告导出操作，触发失败场景：当前无可导出数据或导出格式异常<br>3.操作执行失败<br>4.返回OS门户查看日志中心
            预期：1.工具侧报告导出操作失败并给出明确提示<br>2.OS门户日志中心按需求记录失败操作日志（含操作结果=失败及失败原因），或不产生错误日志<br>3.无重复日志、无日志丢失
          • 软件执行码检测工具|报告导出边界值+日志处理 功能测试 P3
            1.在软件执行码检测工具中执行报告导出操作，输入边界值（如对象名称长度为1/最大长度/超长）<br>2.操作完成后查看OS门户日志
            预期：1.边界输入在工具侧得到正确校验（允许或拒绝）<br>2.OS门户日志记录与工具侧结果一致<br>3.日志中特殊字符/超长文本正常显示或转义，不报错
        • 异常场景
          • 软件执行码检测工具|报告导出+日志同步网络中断处理 功能测试 P3
            1.登录OS门户并跳转到工具<br>2.执行报告导出操作<br>3.在日志同步过程中模拟网络中断/服务异常<br>4.恢复网络后重新检查OS门户日志
            预期：1.工具侧报告导出操作不受日志同步失败影响（不回滚）<br>2.网络恢复后日志可自动补传成功，或给出明确失败提示与重试机制<br>3.无日志重复或丢失
          • 软件执行码检测工具|报告导出+多用户并发日志完整 功能测试 P3
            1.多用户（如A、B两用户）同时登录工具<br>2.同时执行报告导出操作<br>3.在OS门户日志中心检查记录
            预期：1.并发操作的日志逐条完整记录，不丢失、不串号<br>2.每条日志的操作人、对象、时间正确对应<br>3.日志同步不产生冲突或覆盖
        • 正向场景
          • 软件执行码检测工具|报告导出成功+日志同步OS门户成功 功能测试 P1
            1.登录OS门户，通过OS门户跳转到软件执行码检测工具<br>2.在工具侧执行报告导出操作<br>3.操作成功后，返回OS门户<br>4.在OS门户日志中心查询该操作的日志
            预期：1.报告导出操作执行成功，工具侧无报错<br>2.OS门户日志中心新增对应日志<br>3.日志内容准确：工具名称、操作类型=报告导出、操作人、操作时间、操作对象、执行结果=成功<br>4.日志同步及时，时间与工具侧操作时间一致
          • 软件执行码检测工具|报告导出日志字段完整性验证 功能测试 P2
            1.完成软件执行码检测工具的报告导出操作<br>2.打开OS门户日志中心<br>3.查看该条日志详情
            预期：1.日志详情字段完整：工具名称、操作类型=报告导出、操作人、操作时间、操作对象、操作结果、详情/备注<br>2.各字段与工具侧实际操作一致<br>3.无乱码、无字段缺失
      • 接口测试
        • 报告导出接口
          • 软件执行码检测工具|报告导出接口-正常导出成功+日志上报 接口测试 P1
            1.调用报告导出接口，传入导出条件<br>2.校验返回文件流/下载地址<br>3.校验日志上报
            预期：1.接口返回200及有效文件流或下载地址<br>2.文件内容与条件一致<br>3.日志上报OS门户，结果=成功
          • 软件执行码检测工具|报告导出接口-空数据导出 接口测试 P2
            1.调用导出接口，构造无匹配数据的条件<br>2.校验返回
            预期：1.接口返回空文件或明确提示无可导出数据<br>2.不报错<br>3.日志记录导出结果（成功或提示）
          • 软件执行码检测工具|报告导出接口-大数据量导出性能 接口测试 P3
            1.调用导出接口导出全量数据<br>2.记录响应时间
            预期：1.导出成功且响应时间在可接受范围内<br>2.文件生成完整无截断<br>3.接口不超时崩溃
        • 批量新建项目接口
          • 软件执行码检测工具|批量新建项目接口-批量全部成功+日志逐条 接口测试 P1
            1.调用批量操作接口，传入10条数据<br>2.校验返回<br>3.校验日志上报
            预期：1.接口返回成功，10条全部处理<br>2.日志逐条上报共10条<br>3.每条结果正确
          • 软件执行码检测工具|批量新建项目接口-部分失败处理 接口测试 P2
            1.调用批量接口，含2条非法数据<br>2.校验返回
            预期：1.接口返回部分成功部分失败（含明细）<br>2.成功项正常处理，失败项给出原因<br>3.日志分别记录成功/失败
          • 软件执行码检测工具|批量新建项目接口-空批量/重复提交幂等 接口测试 P3
            1.传空列表调用批量接口<br>2.使用相同批量参数重复调用2次
            预期：1.空列表返回参数校验错误或空处理结果<br>2.重复调用结果一致，不重复处理<br>3.日志不重复记录
        • 日志上报接口
          • 软件执行码检测工具|工具操作触发日志上报接口成功 接口测试 P1
            1.在软件执行码检测工具执行任一操作<br>2.抓包验证日志上报接口被正确调用<br>3.在门户日志中心核对
            预期：1.操作后自动触发日志上报接口调用<br>2.接口参数包含正确的工具标识与操作信息<br>3.门户日志中心同步可见
          • 软件执行码检测工具|日志上报接口凭证失效处理 接口测试 P2
            1.使日志上报接口凭证失效<br>2.在软件执行码检测工具执行操作<br>3.恢复凭证后再次操作
            预期：1.凭证失效时上报失败，工具侧给出明确提示<br>2.不影响工具侧操作本身<br>3.恢复后新操作日志正常上报，不阻塞
        • 删除项目接口
          • 软件执行码检测工具|删除项目接口-正常删除成功+日志上报 接口测试 P1
            1.构造删除项目接口请求（对象ID正确）<br>2.调用删除接口<br>3.校验返回<br>4.校验日志上报
            预期：1.接口返回成功<br>2.对象删除成功<br>3.日志上报OS门户，结果=成功
          • 软件执行码检测工具|删除项目接口-对象不存在返回错误 接口测试 P2
            1.构造请求，传入不存在的对象ID<br>2.调用删除接口<br>3.校验返回
            预期：1.接口返回404或对应错误码<br>2.提示对象不存在<br>3.不产生错误日志
          • 软件执行码检测工具|删除项目接口-无权限删除被拒绝 接口测试 P2
            1.使用无权限凭证调用删除接口<br>2.校验返回
            预期：1.接口返回403或权限错误码<br>2.删除失败，数据未被删除<br>3.记录权限校验结果
          • 软件执行码检测工具|删除项目接口-状态前置校验+并发删除 接口测试 P3
            1.调用删除接口删除被引用（发布中）的对象<br>2.两用户并发删除同一对象
            预期：1.被引用对象返回删除前置校验失败<br>2.并发删除同一对象仅一次成功，另一次返回对象已不存在<br>3.日志准确记录最终结果
        • 新建项目接口

            预期：1.接口返回成功状态码（如200/201）<br>2.数据创建成功<br>3.触发操作日志上报OS门户，日志内容与本次操作一致

            预期：1.接口返回参数校验错误（如400）<br>2.不创建数据<br>3.返回明确错误码与提示
          • 软件执行码检测工具|新建项目接口-参数类型/长度越界/特殊字符 接口测试 P2

            预期：1.接口返回参数校验错误<br>2.不创建数据，无异常堆栈泄露<br>3.特殊字符被过滤或转义
          • 软件执行码检测工具|新建项目接口-重复提交幂等性 接口测试 P3
            1.使用完全相同参数连续调用创建接口2次<br>2.校验数据与日志
